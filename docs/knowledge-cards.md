# 知识卡格式

`knowledge/` 下的每个 `.md` 都是一张知识卡，被 `knowledge_search` 按关键词打分检索（标题命中 +3 / 关键词 +2 / 正文每词最多 +3，取前 3）。

frontmatter 三个字段：

```markdown
---
name: card-id          # 唯一 id，小写连字符
title: 一句话标题       # 检索权重最高
keywords: 词1, 词2, …  # 逗号分隔，中英文都放
---

正文：现象 → 触发条件 → 规避规则。写给 agent 执行，不写给人看。
```

- 目录只做归类（如 `pipeline/`），检索时递归扫描全部 `.md`。
- 卡片应来自**本项目实测**或**可引用的公开文档**；每张卡建议注明来源（代码路径 / 文档 URL）。
- 用户也可在 `userData/skills/` 同级放自己的知识目录（设置 → 知识库路径）。
