# 执行剧本：音乐 MV

## 1. 素材盘点
- 用户自带音频 → `canvas_node_add_file` 导入；没带 → 先澄清（要不要现成 `music_generate`？风格？时长？）。
- `media_probe` 取音频时长；`media_analyse`（可选）理解音频情绪走向。
- `recall` 查歌手/品牌/形象约束，命中即遵循。

## 2. 分段与对句
- 按 8–16 秒一段切分时间轴，写出每段的画面意图与口型/字幕需求。
- `canvas_node_add_table` 出分段表（段号/时间区间/画面/歌词）⛳ 用户确认。
- 有歌词需要烧字幕 → 文本节点存定稿歌词，⛳ 确认后才能进生成。

## 3. 视觉风格样 ⛳
- 每段先出 1 张首帧候选（同风格锚串联），挑定后 `remember` 记录风格决策。

## 4. 逐段生成
- `plan_create`：每段一个阶段（waiting→doing→done），逐段 首帧 → 图生视频（时长贴齐段长）。
- 段落间转场意图写进提示词（首尾帧衔接用上一镜尾帧做 ref）。

## 5. 混剪与合轨
- `videos_merge` 按段序拼接 → 抽取音轨/合成：视频用画面，音频一律替换为用户的轨道（`extract_audio` + ffmpeg 合成工具链）。
- 需要歌词字幕 → `subtitle_burn`。

## 6. 质检交付
- `media_analyse` 对照分段表核查（段对位、口型/字幕、风格漂移）→ 回改不达标段。
- 交付列名（成片/分段表/音频源），plan 全 done，`remember` 沉淀本 MV 的可复用决策。
