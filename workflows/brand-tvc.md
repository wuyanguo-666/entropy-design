# 执行剧本：品牌 TVC

按顺序执行；带 ⛳ 的是检查点——必须拿到用户确认才能继续。

## 1. 品牌锚定（不落任何生成调用）
- `recall` 查本项目记忆：主色、logo 使用规则、语气词、既往采纳风格。命中即遵循。
- 缺关键事实（品牌名 / 一句话卖点 / 视觉资产）→ `ask_user` 一次问全（推荐项置顶）。
- 有 logo/产品图等资产 → `canvas_node_add_file` 导入画布，作为后续 `ref_node_ids`。

## 2. 立计划
- `plan_create`：阶段固定为 风格样例 → 分镜表 → 逐镜生成（每镜一阶段）→ 配音配乐 → 合成质检 → 交付。
- 概述计划一条消息发给用户 ⛳（等待确认或修改）。

## 3. 风格样例（首帧定调）
- 图片模型出 1–2 张"广告感最强"的首帧候选（带品牌资产做 `ref_node_ids`）。
- ⛳ 用户选定后，选中图 = 全片风格锚，记 `remember`（风格决策 + 理由）。

## 4. 分镜表
- `canvas_node_add_table` 出分镜表（镜号/时长/画面/运镜/旁白），后续小改一律 `canvas_text_patch`。
- 比例直通纪律：全片画幅以澄清结果为准，表格与提示词不许悄悄改比例。
- ⛳ 分镜表确认后才逐镜。

## 5. 逐镜生成（每镜一个精简循环）
- 每镜：该镜首帧（以风格锚为首帧参考）→ 图生视频 → 产物落画布（自动溯源边）。
- 单镜失败先 `knowledge_search` 查失败卡对症修正，连续两次失败才向用户报卡点。

## 6. 配音配乐 + 合成
- 旁白稿写文本节点 ⛳ 确认 → `speech_generate`（音色沿用记忆）。
- `music_generate` 出底乐（可 0 首，听用户诉求）。
- `videos_merge` → `subtitle_burn`（如需）→ `embed` 用 ffmpeg 工具链完成音画合成。

## 7. 质检与交付
- `media_analyse` 看成片（对照分镜表逐镜核对 + 品牌安全），不达标回改对应阶段（`plan_stage_state_update` 回拨）。
- 交付：文件名反引号列出（成片 + 分镜表 + 关键素材），`plan_stage_state_update` 全部 done。
