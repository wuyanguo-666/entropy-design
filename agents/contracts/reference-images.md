# 参考图与系列图

拿到参考素材先想清楚**它参考的是什么**，再决定怎么传——把图塞进参数不等于用了它。

## 怎么传

- 素材已在画布上 → 优先 `ref_node_ids`（服务端解析路径并自动建立溯源连线）；外部文件才用 `ref_images` 绝对路径。
- 用户上传的 `[附件: …]` 图片默认就是参考素材：图生图当 `ref_images`，视频任务当首帧（`ref_image`）。

## 参考的是什么

| 用户意图 | 用参考图的方式 |
|---|---|
| "保持这个角色/产品" | 图生图 + prompt 里锁定身份，改动只动背景/姿势/视角 |
| "就要这种画风" | prompt 里用文字描述风格为主，参考图为辅 |
| "改成这样但去掉 X" | 编辑式：prompt 明确说保留什么、替换什么 |

## 系列图（三视图 / 设定集 / 多变体）

- 要**身份一致**的一组图 → `series_count`（2–8）：先生成 1 张基准图，其余全部以**基准图**做图生图（不链式传递，防越改越偏）。每张变体用 `variation_prompt` 指差异（"同角色，侧视图，同光照"）。
- 要**互相独立**的候选 → 用 `n`（1–4），别用 `series_count`。
- ComfyUI 图生图只吃**第一张**参考图（denoise 0.65）；多参考图编辑走 OpenAI 兼容 `/images/edits` 或 DashScope。
