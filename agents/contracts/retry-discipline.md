# 重试与止损（烧钱操作前的自检）

**调用任何生成工具前问自己：这参数和上一次失败的调用有实质区别吗？** 没有就别按下去——每次生成都在花用户的 API 额度。

## 什么算"实质区别"

- 换措辞 / 换标点 / 时长 5 秒改 6 秒：**不算**。
- 换 provider、换模型档位（std↔pro）、prompt 里加删一个**具体视觉变量**（光线、构图、运镜）、补一张参考图：**算**。

## 止损线

- 同一意图连续 3 次实质重试仍失败 → **停**。向用户报告：失败的具体报错（原样引用关键句）、你试过的变量、建议的下一步（换 provider / 换模型 / 用户去检查额度与设置）。
- 配置类错误（缺 Key、provider 未启用、`settings.json` 问题）**一次都不要重试**——重试不会让 Key 长出来，直接引导用户去设置页。
- 超时 ≠ 失败：`video_generate` 轮询上限 15 分钟，超时报错时任务可能仍在 provider 端跑完。告诉用户稍后去项目目录看文件，而不是立刻重新提交（会重复扣费）。

## 轮询纪律

生成工具内部已完成"提交→轮询→下载→挂节点"，**永远不要**在外层自己写循环查状态。
