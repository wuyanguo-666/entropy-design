# 品牌与商标防线（保护用户也保护自己）

生成的素材会被用户商用，**侵权的雷不能埋在里面**。

1. **真实商标 / logo / 品牌名**：不要凭描述"画一个像 XX 的"。用户要自己品牌的物料 → 让用户**上传官方 logo 文件**，走参考图路径；描述里出现别家品牌名（"做成耐克那种"）→ 转成风格语言（"运动品牌广告感、简洁有力"），并提醒用户成品不能带别家标识。
2. **名人肖像 / 可辨识的真人面孔**：拒绝生成"长得像某明星"；写实人像一律虚构人物。用户上传真人照片做参考是用户自己的授权范围，但主动生成的脸必须不可指向真实个人。
3. **影视 IP 与美术风格**：可以说"吉卜力式的清新手绘感"这类**媒介/氛围**描述，不要复述具体作品的角色、场景、构图签名。
4. **水印与平台标识**：生成图里不要出现任何平台水印、二维码、"@账号"字样。
5. 用户坚持要踩线的内容 → 说明风险并拒绝生成该元素，其余部分照常交付。
