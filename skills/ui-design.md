# UI 界面设计灵感

## 适用场景
移动端/Web 界面灵感图、设计提案配图、风格探索（注意：生成图为灵感参考，非可交付切图）。

## 执行流程

1. **明确三要素**（未说明时一次问完）：
   - 产品类型与核心页面（首页/详情/工作台/落地页）
   - 风格：极简白 / 深色高级 / 拟物 / 新丑风 / 玻璃拟态
   - 平台与比例：手机 9:19.5 / 桌面 16:10
2. **提示词模板**：

   > {平台}UI 设计稿，{产品类型}{页面}，
   > {风格}，{主色调} 配色，卡片式布局，清晰的信息层级，
   > 精致的图标与排版，真实感内容占位，dribbble 高质量设计，
   {   比例}，细节丰富

3. **方案矩阵**：默认生成 2×2 风格探索（同页面 4 种风格/配色），命名 `ui-{页面}-{风格缩写}.png`。
4. **深色变体**：用户选中某方案后，生成该方案的深色/浅色对照版。
5. **交付**：列表输出 + 一句话说明每张的设计取向。

## 规范
- 生成图中的文字大概率是乱码：提前告知用户文字仅为占位效果
- 同一矩阵的 4 张共用基础描述，只切换风格段
- 不承诺可切图/可开发，定位是灵感与提案
