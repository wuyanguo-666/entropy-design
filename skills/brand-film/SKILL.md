# 品牌短片（≤15 秒）

以品牌广告导演身份工作。目标成片 ≤15 秒、单条、品牌官方或产品主角视角 → 本技能；先过入口判定，再走流程。

## 入口与分流

- 达人/用户亲身体验类（试用、开箱、口播、POV）→ 不归本技能，转 `video-promo` 或按普通任务直发。
- 超 15 秒、完整剧情、多场景连续、同主体系列多条 → 转 `storyboard` 立交付计划。
- 只有 Logo/产品图、没有广告意图 → 当普通图任务处理。
- 官方视角与体验视角混在一起分不清 → `entropy_ask_user` 问一次"这条偏用户体验分享还是品牌官方广告？"，不猜。
- 用户没给时长 → 选路线前补问；参考素材本身超 15 秒不拦路，按目标成片截取即可。

## 品牌资产与事实

1. 用户给的 Logo/产品/包装/截图先 `entropy_canvas_node_add_file` 入画布，再 `entropy_media_analyse` 建事实清单：品牌名、主色、材质、可见卖点、已有文案。
2. **真实身份不可伪造**：不生成、不重绘、不"画个像 XX 的"真实 Logo、字标、包装文字、奖项或数据指标；正式标识只用用户提供的图像资产。
3. 产品名、口号、CTA、免责文字只能来自用户输入或已分析素材；查无出处就不写。新品牌/概念片可原创文案，但交付时标注"概念演绎，非官方物料"。

## 三条创意路线（内部判定，不对用户暴露路线名）

| 路线 | 触发信号 | 叙事骨架 |
|---|---|---|
| 标识演变 | Logo/视觉体系的"草稿→定稿、reveal、升级过程" | 手稿态 → 元素拼贴 → 成品定格 |
| 质感情绪 | 材质、工艺、氛围、灯箱、微距是主角 | 陈列 → 微距质感 → 工艺动作 → 留白收尾 |
| 单品 Hero | 具体产品是唯一主角 + 商业成片诉求 | 身份锁定 → 锚定特写 → 动态 Hero |

同时命中按表序取先；判不出来就给 2 个方向让用户选。

## 风格母题（一次问全）

写分镜前 `entropy_ask_user` 一轮问齐：风格方向（3–4 个**可观察**的具体选项，推荐置顶）、时长/画幅、要不要旁白、CTA 文案。答案收敛成一句视觉母题 + 6–8 个可观察风格词（光色/材质/运镜语法），之后每条 prompt 都消费它。反面清单：不许把所有品牌都做成"慢推产品 → 两个特写 → Logo 定格"的模板片。

## 节拍表与生成

1. ≤15 秒拆 3–6 个节拍，每节拍记：起止秒 / 主体 / 一个主动作 / 转场承接。秒数按视觉呼吸分配，不平均分。
2. 关键帧先行：`entropy_image_generate`（产品身份锚定用 `series_count` 出同主体多角度）→ 用户确认 → 逐节拍 `entropy_video_generate`，首帧=确认的关键帧，`source_node_id` 挂溯源链。
3. 长操作前打招呼；每节拍成片上画布后按 Self-Review 规则质检——产品变形、Logo 扭曲是本品类高频翻车点，不合格改一个实质变量重试，止损纪律见 retry-discipline 契约。

## 定版与交付

- 屏幕文字/CTA **不交给视频模型画**：生成干净底片后用 `entropy_subtitle_burn`（ASS 样式）叠加；位置精度有限，用户要像素级排版时交付无字版 + 文字层说明。
- BGM：问一次要不要独立配乐；要则 `entropy_music_generate` 单独交付并如实说明本项目无混音通道（用户端合成或接受原声）。
- 交付清单：成片 + 关键帧 + 节拍表文本节点；回复注明时长/画幅/路线摘要/素材出处，概念片标明边界。
