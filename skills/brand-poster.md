# 品牌主视觉 / 海报

## 适用场景
品牌 KV、活动海报、产品宣传主图、社交媒体封面。

## 执行流程

1. **锁定三要素**（用户未说明时先问，一次问完）：
   - 主体：品牌/产品/活动是什么，画面核心对象
   - 风格方向：极简 / 高级感 / 潮流 / 国潮 / 3D / 摄影感
   - 用途与比例：线上传播 3:4 / 海报 2:3 / 横版 16:9
2. **建立方案节点**：用 `entropy_canvas_node_add_text` 写一个「设计方案」节点，包含：主题句、风格关键词（5-8 个）、配色建议（3 色）、字号层级建议。
3. **主视觉生成**（1-2 张）：提示词模板——

   > 主视觉海报设计，{主体描述}，{风格关键词}，大胆的标题排版 "{标语}"，
   > 构图 {居中/对角线/留白式}，{配色}，商业摄影质感/高端渲染，
   {   比例}，细节丰富，8k

4. **变体延展**：在主视觉满意后，生成 2-3 张同风格变体（换构图/换配色/换场景），保持同一 style 前缀句。
5. **交付**：每张图以 `- 名称：\`文件名.png\`` 列出。

## 规范
- 文件命名：`brand-{方案号}-{序号}.png`
- 文字渲染不稳时，先出无字版，再提示用户后期加字
- 一次对话内的所有变体共用同一段风格前缀，保证系列感
