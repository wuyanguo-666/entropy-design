# 分镜故事板

## 适用场景
短片、TVC 广告、动画、MV 的前期分镜，逐镜静态画面预演。

## 执行流程

1. **拆解叙事**：根据用户主题把内容拆成 4-8 个镜头，确定每镜的：
   - 景别（远/全/中/近/特写）
   - 机位与运动（俯拍/平视/低角度，推拉摇移）
   - 画面内容一句话
   - 情绪/氛围关键词
2. **计划节点**：`entropy_canvas_node_add_text` 建「分镜表」节点，逐行列出镜号、景别、内容、氛围。
3. **统一风格前缀**（所有镜头共用，保证连贯）：

   > {题材}分镜，{统一视觉风格：如 赛博朋克/吉卜力水彩/电影胶片质感}，
   > 统一色调 {色彩}，电影级构图，景深自然，16:9

4. **逐镜生成**：每镜一次 `entropy_image_generate`，prompt = 风格前缀 + 该镜内容 + 景别 + 机位。逐镜命名 `shot-01` … `shot-06`。
5. **逐镜确认**：全部生成后按镜号列表交付；用户指出需重做的镜头时，只重生成该镜并保持前缀不变。

## 规范
- 默认 16:9；用户指定竖屏短视频时用 9:16
- 镜头间主体特征保持一致（服装/角色描述逐字复用）
- 同一主体多镜出现时，把主体描述完整放进每镜 prompt，不省略
