# 视频任务在集成层怎么跑（依据 mcp/video-providers.mjs）

- 一次 `video_generate` = 提交 → 每 5 秒轮询 → 完成后下载 mp4 进项目目录 → 自动挂视频节点。**外层不要自己轮询、不要中途重复提交**。
- 轮询硬上限 **15 分钟**，超时抛 "video generation timed out"。此时 provider 端任务可能仍在跑并稍后完成——正确动作是告诉用户"稍后看项目目录 / 再查一次"，**不是**立即重新提交（重复扣费）。
- 失败报错分两类：提交即错（鉴权 / 参数 / 配额）→ 属配置或参数问题，按重试契约处理；轮询期状态 Fail → 内容审核或 provider 侧故障，改 prompt 一个实质变量再试一次，仍失败就报告用户。
- 生成耗时正常区间 1–10 分钟：用户等 3 分钟没结果**不是**失败信号，别提前重试。
